# Legends of Arcadia

Welcome to **Legends of Arcadia**, a 2D RPG built from scratch in Java using Java2D. Big props to [RyiSnow](https://www.youtube.com/@RyiSnow) for his inspiring game development tutorials, which served as the foundation for this project. Building on those core concepts to deepen my Java skills, I’ve expanded the game with my own custom ideas and original pixel art.
